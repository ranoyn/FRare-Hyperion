# 旧F! レアキャHyperion v1.0.0

「電波人間のRPG FREE!」向けの非公式ツールです。
任天堂・ジニアス・ソノリティによる公式製品ではありません。

本ツールの使用によって生じた損害・不具合について、作者は責任を負いません。
予測・計算結果はゲーム内でも確認し、自己責任でご利用ください。

新規ドーピングメモは、ほかの機能を利用しなくても単独で利用できます。
レアキャ検索・出生解析を利用する際は、特定ツールから始めてください。

## 特定ツール

レアキャッチに最初に出現する10人の名前・アンテナ・頭・体色などの情報を入力するか、そのうち1人をキャッチして顔パーツを含む情報を入力し、レアキャ検索に必要な予測キーを検索します。

体色の黒は目視での濃淡の確認が難しいため、濃淡を設定できないようにしています。
使用スレッド数を増やすと検索が速くなる場合がありますが、PCへの負荷も大きくなります。

検索結果が出ない場合は、その日にレアキャッチに出現する電波人間をすでに捕まえている可能性があります。
3DS本体の年を大きく変更するなどして、新しく出現した個体の情報で再検索してください。

## レアキャ検索

特定ツールで特定した予測キーを入力してください。
3DS本体を引っ越した場合は、特定ツールから予測キーを特定し直してください。
補充枠は1日最大69枠、最初の10人と合わせて最大79人分の候補を検索できます。

## ゲキレア検索

ゲキレアキャッチの乱数調整を目的に作成している機能です。
現在は開拓が進んでいないため、この機能単体で乱数調整を行うことはできません。
指定したseedで出現する電波人間を検索できます。

## 出生解析

レアキャ検索で保存した結果を用いてご利用ください。
出生解析で保存した結果は、「ドーピングメモ・ルート確認」でドーピングの配分を自動計算できます。
